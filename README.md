# Data Pipeline Monitor

A self-contained Streamlit app for **spotting data-quality problems in a messy, synthetic warehouse**. It loads Parquet snapshots generated by [chaoslake](https://pypi.org/project/chaoslake/) and surfaces nulls and duplicates — the two failure modes that quietly break downstream pipelines.

Everything runs locally: no database, no network calls, no external services. The "warehouse" is just a couple of Parquet files in `data/`.

---

## Features

- **Overview metrics** — table count, total rows, and per-table row/column summary.
- **Null Report** — per-column null counts for every table, with:
  - Affected-column and total-null counts,
  - A "worst offender" callout,
  - A progress-bar view of null percentage.
- **Duplicate Report** — per table:
  - Full-row duplicates (identical rows),
  - **Business-key duplicates** (all columns *except* the surrogate `id`), which is what a real idempotency bug looks like,
  - Duplicate percentage with a "worst offender" callout.
- **Cached loading** — Parquet files are read once and cached via `st.cache_data`.
- **Clean UX** — success banners when a report is empty, so a healthy warehouse looks healthy.

## Project structure

```
.
├── app.py                  # Streamlit app (all report logic lives here)
├── data/
│   ├── chaoslake.yaml      # Schema + chaos configuration
│   ├── gen.sh              # Regenerates the Parquet files
│   ├── customers.parquet   # 1,000 synthetic customers
│   └── orders.parquet      # 5,000 synthetic orders
└── pyproject.toml          # Dependencies (managed with uv)
```

## Requirements

- **Python ≥ 3.12**
- **[uv](https://docs.astral.sh/uv/)** for dependency management
- **[chaoslake](https://pypi.org/project/chaoslake/) ≥ 0.1.2** (installed automatically as a dependency; also provides the `chaoslake` CLI used by `gen.sh`)

---

## Getting started

```bash
# 1. Install dependencies
uv sync

# 2. (Optional) regenerate the synthetic data
cd data && ./gen.sh && cd ..

# 3. Run the app
uv run streamlit run app.py
```

Then open the URL Streamlit prints (usually <http://localhost:8501>).

> The repo already ships with `customers.parquet` and `orders.parquet`, so step 2 is only needed if you want fresh data or want to tweak the chaos levels.

## Tech stack

- **[Streamlit](https://streamlit.io/)** — UI and caching
- **[Polars](https://pola.rs/)** — fast, lazy-friendly DataFrame operations for loading and analyzing Parquet
- **[chaoslake](https://pypi.org/project/chaoslake/)** — schema-driven synthetic data with configurable, realistic chaos
